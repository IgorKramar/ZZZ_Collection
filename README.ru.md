**Разожги горн, собери станок, распаши поле, почини грузовик.**
ZZZ — индустриальная сборка выживания для Project Zomboid **Build 42.20.2+**. Этот репозиторий содержит настройки, которые не устанавливаются вместе с подпиской в Мастерской: список включённых модов, правила порядка загрузки и руководства на русском и английском.

Стартовый набор рассчитан на **100 включённых модов**; в его документации зафиксирована проверка на **42.20.2**. Моды Мастерской и новые версии игры меняются независимо: наличие набора не означает, что каждое текущее сочетание проверено заново.

## Установка

1. В Steam откройте **Project Zomboid → Свойства → Бета-версии** и выберите ветку `b42`, указанную в стартовом наборе.
2. Откройте [коллекцию в Мастерской](https://steamcommunity.com/sharedfiles/filedetails/?id=3778214259), нажмите **«Подписаться на все»** и дождитесь загрузки всех модов (несколько ГБ).
3. Скачайте [`ZZZ_Collection_StarterKit.zip`](ZZZ_Collection_StarterKit.zip). **Закройте игру и сохраните копии существующих `default.txt` и `sorting_rules.txt` перед переносом:** файлы из набора заменят ваш текущий список модов и правила загрузки.
4. Скопируйте `Zomboid/mods/default.txt` из архива в `C:\Users\<имя>\Zomboid\mods\`, а `Zomboid/Lua/sorting_rules.txt` — в `C:\Users\<имя>\Zomboid\Lua\`.
5. Запустите игру. На экране модов нажмите **«Сортировать и принять»** — эту кнопку добавляет **Mod Load Order Sorter**.

Здесь указаны пути профиля Windows. В другой системе или при отдельном профиле используйте его фактический каталог `Zomboid`. Для ручного включения модов следуйте `README_УСТАНОВКА.txt` внутри архива, учитывая исключения ниже.

## Стартовый набор

| Файл в архиве | Назначение |
|:---|:---|
| `README_INSTALL_EN.txt` | Полная инструкция по установке и настройке на английском |
| `README_УСТАНОВКА.txt` | Полная инструкция по установке и настройке на русском |
| `Zomboid/Lua/sorting_rules.txt` | Правила для Mod Load Order Sorter |
| `Zomboid/mods/default.txt` | Готовый список включённых модов |

**В архиве находятся настройки и документация, а не сами моды Мастерской.** Их Steam скачивает отдельно. Сборка или компиляция для использования набора не нужна.

## Совместимость

<details>
<summary><strong>Какие пункты не включать</strong></summary>

- **Capacity Limit Bypass [MANUAL INSTALLATION]** требует ручной замены файлов движка игры. Стартовый набор прямо исключает его: не устанавливайте его в рамках этой сборки.
- **Somewhat Traits Skills** дублирует возможности **Legendary Professions and Traits**. В готовом списке этот сабмод выключен.

</details>

<details>
<summary><strong>Приоритеты карт и ожидаемые предупреждения</strong></summary>

В **Map Mod Manager** выберите, какая карта побеждает на пересечениях:

| Карты | Ячейки |
|:---|:---|
| Constown / New Hartburg | `24_42`–`24_44` |
| Louisville Quarantine Zone / PIE42 | `44_13`, `45_13` |

Инструкция набора относит жёлтые предупреждения об этих пересечениях и `tiledef 7001` (Customizable Containers / Fort Waterfront) к известным особенностям. Другие красные сообщения валидатора нужно сообщать, а не игнорировать.

</details>

<details>
<summary><strong>Первый запуск и Horse Mod</strong></summary>

После включения Horse Mod полностью перезапустите игру перед игрой. Инструкция предупреждает: без перезапуска вместо лошадей могут появиться заглушки анимаций.

</details>

Полные инструкции внутри ZIP описывают настройки именно этого набора. Обновления игры и коллекции в Мастерской могут потребовать изменений.
